# Settling the Optimal Exponent Relating Sumsets and Difference Sets

This repository contains the public artifacts for a run-backed reproduction of
[arXiv:2607.27199](https://arxiv.org/abs/2607.27199).

## Reproduction

- [Detailed scientific report](reproduction/report.md)
- [Self-contained marimo notebook](reproduction/notebook.py)
- [Open the notebook in Molab](https://molab.marimo.io/github/alphaXiv/settling-the-optimal-exponent-relating-sumsets-a/blob/main/reproduction/notebook.py)

The reproduction used 14 successful Kubernetes runs. The notebook embeds the
reported measurements and regenerates the five evidence figures interactively.
